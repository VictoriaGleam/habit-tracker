# Gantt Chart – Habit Tracker (3 veckor)

Detta dokument visar den övergripande tidsplanen för projektet.  
Varje vecka har tydliga mål och dagliga aktiviteter.

---

## Vecka 1 – Planering & Struktur
**Mål:** Färdig dokumentation, projektstruktur, databasdesign och frontend‑grund.

### Måndag
- Definiera funktioner
- Definiera vad som inte ingår
- Bestäm målgrupp
- Skissa roller (User/Admin)
- Skissa vyer
- Välj tekniker
- Skapa projektstruktur

### Tisdag
- Skapa databasdesign (ER‑diagram)
- Skapa database.js
- Skapa initTables.js
- Skapa tabeller i SQLite
- Skapa backend‑mappar (controllers, models, routes)

### Onsdag
- Skapa grundlayout i index.html
- Skapa bas‑CSS (färger, typsnitt, layout)
- Skapa tom script.js

### Torsdag
- Dokumentera frontend‑plan (sidor, komponenter, navigation)
- Dokumentera backend‑plan (routes, controllers, models)
- Förtydliga roller och vyer

### Fredag
- Skapa README.md
- Skapa scope.md
- Skapa gantt.md
- Pusha allt till GitHub
- Skapa Trello/GitHub Projects board

---

## Vecka 2 – Backend & User‑funktioner
**Mål:** Färdig backend för användare, vanor och loggar. User Dashboard fungerar.

### Måndag
- Implementera CRUD för habits (create, read, update, delete)

### Tisdag
- Implementera habit_log (markera dagar)
- Koppla loggar till vanor

### Onsdag
- Implementera register/login
- Hasha lösenord
- Skapa JWT/session

### Torsdag
- Koppla frontend till backend (User Dashboard)
- Hämta vanor från API
- Visa lista i HTML

### Fredag
- Implementera statistik (procent, streaks)
- Testa hela user‑flödet
- Fixa buggar

---

## Vecka 3 – Admin, Design & Presentation
**Mål:** Admin Dashboard, design, testning och presentation.

### Måndag
- Skapa Admin Dashboard
- Visa alla användares vanor

### Tisdag
- Lägg till filter och sök
- Förbättra admin‑översikten

### Onsdag
- Förbättra design (UI/UX)
- Mobilanpassning
- Ikoner, färger, layout

### Torsdag
- Testning av hela systemet
- Fixa buggar
- Förbered demo‑data

### Fredag
- Skapa presentation (PowerPoint/Keynote)
- Öva presentationen
- Slutlig genomgång

---

## Sammanfattning
Vecka 1: Planering + struktur  
Vecka 2: Backend + User‑funktioner
