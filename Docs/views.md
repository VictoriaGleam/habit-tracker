# Views & User Roles

## User (Vanlig användare)
### Dashboard
- Visa lista över vanor
- Markera dagar som fullföljda
- Se enkel statistik (progressbar, procent, streaks)

### Habit Details
- Visa detaljer om en vana
- Se historik/loggar
- Redigera eller ta bort vana

---

## Admin
### Admin Dashboard
- Se alla användares vanor
- Se statistik per användare
- Filtrera på användare
- Sök efter vana eller användare

### Admin Tools
- Hantera användare (visa, filtrera)
- Övervaka aktivitet (habit_log)
