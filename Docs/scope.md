# Scope – Habit Tracker

## 1. Projektets omfattning
Habit Tracker är en webbaserad applikation där användare kan skapa vanor, markera dagliga framsteg och se enkel statistik. Fokus ligger på att bygga en fungerande prototyp med tydlig struktur, enkel design och grundläggande funktionalitet.

Projektet utvecklas som ett MVC-projekt med:
- Backend: NodeJS + Express
- Frontend: HTML, CSS, JavaScript
- Databas: SQLite

---

## 2. Funktioner som ingår i prototypen
### User
- Skapa vanor
- Markera dagar som fullföljda
- Visa enkel statistik (t.ex. procent, streaks)
- User Dashboard med lista över vanor

### Admin
- Admin Dashboard
- Se alla användares vanor
- Filtrera och söka

---

## 3. Funktioner som inte ingår
- Push-notiser
- Sociala funktioner
- Gamification (badges, poäng)
- Export av data
- Delning av statistik
- Mobilapp-version

---

## 4. Begränsningar
- Endast grundläggande UI (ingen avancerad design)
- Endast enkel statistik
- Endast två roller (user/admin)
- Endast lokal databas (SQLite)

---

## 5. Syfte
Syftet är att skapa en tydlig och användbar prototyp som visar:
- MVC-struktur
- Backend + databaslogik
- Frontend som kommunicerar med backend
- Roller och vyer
- En fungerande helhet från databas → backend → frontend

---

## 6. Målgrupp
- Studenter
- Yrkesverksamma
- Personer som vill skapa och följa dagliga rutiner
