# Habit Tracker – Final Project

## 1. Beskrivning
Habit Tracker är en webbaserad applikation där användare kan skapa vanor, markera dagliga framsteg och se enkel statistik. Admin-användare kan se en översikt över alla användares vanor.

Projektet är byggt som ett MVC-projekt med NodeJS, Express, SQLite och HTML/CSS/JavaScript.

---

## 2. Funktioner
### User
- Skapa vanor
- Markera dagar som fullföljda
- Se statistik
- User Dashboard

### Admin
- Admin Dashboard
- Se alla användares vanor
- Filtrera och söka
